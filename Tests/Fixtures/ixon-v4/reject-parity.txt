# Byte strings every reader of their kind must refuse, in Rust
# (crates/ixon/tests/reject_parity.rs, every kind but ixes)
# and in Lean (Tests/Ix/IxonRejectParity.lean, the `ixon-reject-parity`
# suite), with accepted controls beside them. Records are Ixon v5: each ends
# with its binder-data section, and carries its modes there and in its
# definition and constructor bytes.
#
# One case per line: <kind> <name> <tokens…>. A token is hex bytes, or XX*N
# for the byte XX repeated N times. Kinds, and the readers each must agree on:
#
#   record          every constant decoder (Rust Constant::get on exactly the
#                   bytes; Lean's canonical, bounded and window decoders and
#                   the refs-only reader)
#   noncanonical    the canonical constant decoders (Rust Constant::get on
#                   exactly the bytes; Lean Canonical.deConstant)
#   canonical-rule  the canonical constant decoders (Rust
#                   Constant::get_canonical; Lean Canonical.deConstant): a
#                   record rule beyond the codec refuses these bytes, which
#                   the codec reads (Rust Constant::get)
#   env             the environment readers that read every section (Rust
#                   Env::get and Env::parse_lazy_index; Lean deEnv and the
#                   verified loader)
#   ixes            the shard-manifest readers
#   tree            the assumption-tree readers (exactly the bytes)
#   claim           the claim readers (exactly the bytes)
#
# A kind with an `-accept` suffix is a control every such reader accepts.

# A canonical axiom record: `axiom : Sort u₀`, its universe table [zero], its
# empty binder-data section.
record-accept axiom D2 00 00 00 00 00 01 00 00
# Its universe a successor run of 4,311,814,175: a few bytes that expand to
# billions of universe nodes, beyond every reader's per-record budget.
record univ-run-bomb D2 00 00 00 00 00 01 32 FFFFFFFF 00 00
record truncated D2 00 00 00 00 00 01 00
record trailing-bytes D2 00 00 00 00 00 01 00 00 00

# Universes in non-canonical forms: Max and IMax with a nonzero tag value, and
# one successor run split in two (01 01 00 for the canonical 02 00).

noncanonical univ-imax-value D2 00 00 00 00 00 01 81 00 00 00
noncanonical univ-split-run D2 00 00 00 00 00 01 01 01 00 00
