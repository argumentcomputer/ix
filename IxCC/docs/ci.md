## Current surface

[`nix/checks.nix`](../nix/checks.nix) defines every check, and ix's flake
(`../flake.nix`) exposes each as `ixcc-<name>` (named below without the
prefix). `nix flake check` at ix's root runs them with ix's own check;
`nix build .#checks.x86_64-linux.ixcc-<name>` runs one. In CI,
`.github/workflows/ixcc.yml` runs all of them (with a 60-minute job timeout):
from CI Jobs when a pull request changes IxCC's inputs, and from Merge tests
on every merge group. The set is pinned: the trust ledger's `required_checks`
lists the attributes of `nix/checks.nix` (the `trusted-extern-ledger` check
compares the two), and `ixcc.yml` fails unless the flake's evaluated `ixcc-*`
checks are exactly that list ([trust ledger](trusted-extern-ledger.md)). The
builds they share:
- **`build`** is the production library.
- **`proofs`** builds every executable and the complete proof and fence
  collection (`IxCCTests.Proofs`) once, reusing the library's
  artifacts. Every other check runs those programs against the full tracked
  source tree.

## Rules for returning gates

- **One gate per named check** in `nix/checks.nix`. Build shared artifacts once
  and reuse them across checks (AGENTS.md).
- **Budget:** required checks stay within 30 minutes cold on the configured
  machine. Record elapsed time and peak memory when a gate returns.
- **Exact axiom fences:** a gate that covers a public theorem also restores
  that theorem's fence, and the coverage inventory records it.
