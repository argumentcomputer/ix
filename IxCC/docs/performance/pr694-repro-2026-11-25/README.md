toolchain versions, and exact reproduction commands generated by the hardened
[`bench-k45`](../../../benchmarks/runner/BenchK45.lean) runner on

`"built"` record and SHA-256 digest in `k45-build.json` and passed both
`expected.txt` and `bench_expected` checks.

## Exact reproduction commands

Run from `IxCC/benchmarks/runner/` after building `ixcc` (`cd IxCC && lake build ixcc`)
and `bench-k45` (`cd IxCC/benchmarks/runner && lake build bench-k45`):

```sh
# 1. K1 certified scalar + GCC baselines
./.lake/build/bin/bench-k45 run --rungs K1 --cpu 2 --blocks 10 --gcc \
  --closures ../../fixtures/ixon-v4/bench-k1 --rc off /tmp/pr694-bench/k1-certified

# 2. K1 certified front-end + validated Lir.Opt
./.lake/build/bin/bench-k45 run --rungs K1 --cpu 2 --blocks 10 \
  --closures ../../fixtures/ixon-v4/bench-k1 --rc off --opt /tmp/pr694-bench/k1-opt

# 3. K1 certified + embedded .ix.cert v1 trailer
./.lake/build/bin/bench-k45 run --rungs K1 --cpu 2 --blocks 10 \
  --closures ../../fixtures/ixon-v4/bench-k1 --rc off --embed-cert /tmp/pr694-bench/k1-embed-cert

# 4. K1 experimental BigNat + --opt (with pre-frozen IxCC.BigNat.Entry library)
./.lake/build/bin/bench-k45 run --rungs K1 --cpu 2 --blocks 10 \
  --closures ../../fixtures/ixon-v4/bench-k1 --rc off --bignat --opt \
  --bignat-lib /tmp/pr694-bench/bignat-lib.json /tmp/pr694-bench/k1-bignat-opt

# 5. K4 (array-qsort standalone-exe + blake3 via k45_harness.c) + GCC baselines
./.lake/build/bin/bench-k45 run --rungs K4 --cpu 2 --blocks 5 --gcc \
  --closures /tmp/pr694-bench/k4-closures --rc off --bignat --opt \
  --bignat-lib /tmp/pr694-bench/bignat-lib.json --region 4294967296 /tmp/pr694-bench/k4-bignat-opt
```

## Provenance files per suite

Each subdirectory contains:
- `k45-build.json`: exact CLI invocation (`repro_command`), toolchain versions & `ixcc_sha256`, `ixcc_config` (including `bignat_lib_sha256`), per-row build mode (`standalone-exe` vs `object+harness(...)`), exact compile/link commands, and executable/object/closure SHA-256 digests.
- `k45-samples.json`: raw per-block nanosecond timings, Peak RSS KiB, start/end host environment snapshots, and the verified `binary_sha256` list.
- `k45-report.md` & `k45-report.json`: medians, 95% paired percentile-bootstrap intervals, Peak RSS, rung geometric means, and measured executable artifact table.
